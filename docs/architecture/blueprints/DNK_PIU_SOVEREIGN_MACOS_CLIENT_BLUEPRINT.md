## 1. Архітектурне ядро клієнта (Легкий Huddle-стек на Pure SwiftPM)

### 1.1. Віконний стек (`HuddlePanel: NSPanel`)
- **Базовий протокол**: ~1,500 рядків чистого Swift за зразком `agent-huddle` (замість 53k рядків моноліту Coucou).
- **Стиль вікна**: `[.borderless, .nonactivatingPanel]`. Прапорець `.nonactivatingPanel` дозволяє клікати по віджету без перехоплення фокусу в IDE чи терміналі. Вікно стає `Key` тільки при активному введенні тексту.
- **Рівень вікна (`level`)**: `.floating` (поверх звичайних вікон) або `.statusBar`.
- **Spaces & Fullscreen**: `[.canJoinAllSpaces, .fullScreenAuxiliary, .ignoresCycle]`.
- **Прозорість та геометрія**: плаваюча компактна пігулка (Pill), оптимізована для екрана MacBook Pro 13" M1 (без штучних кривих чолки, вільно перетягується або закріплюється біля Menubar).
- **Збірка**: Нативний `Package.swift` (`swift build -c release`). Збирається за 10 секунд без встановлення `Xcode.app` та без `XcodeGen`. Розмір бінарника < 5 МБ, споживання RAM < 30 МБ.

## 2. Диктування: Google Cloud Vertex AI (Gemini 3.8 Flash Multimodal Audio)

1. **Глобальний хоткей**: `NSEvent.addGlobalMonitorForEvents(matching: [.flagsChanged, .keyDown])` (короткий клік — hands-free, утримання — push-to-talk).
2. **Легковажний захоплювач аудіо (`AudioDictation.swift`)**:
   - Нативний `AVAudioRecorder` (~50 рядків Swift).
   - Запис 16 kHz mono WAV безпосередньо в пам'ять / тимчасовий буфер.
   - **Жодних локальних нейромереж**: 0 МБ сторонніх ваг (повна відмова від Parakeet 650 МБ та Whisper).
3. **Хмарний стенографіст Google Vertex AI**:
   - Відправка аудіо на локальний міст `http://127.0.0.1:11435/v1/audio/transcriptions`.
   - Міст ([coucou_vertex_bridge.py](./scripts/system/coucou_vertex_bridge.py)) автоматично авторизується через наш GCP-акаунт (`dnk.dev.os@gmail.com`, `project-17fe1d8a-b1f4-46ac-87e`) та передає аудіо в **Gemini 3.8 Flash**.
   - Промпт моделі: *"Транскрибуй мову розробника (uk-UA / en-US). Зберігай технічні назви та сленг в оригіналі (Shopify, Clyro, Antigravity, commit, branch, PR, Swift, Python). Автоматично розставляй розділові знаки. Повертай ВИКЛЮЧНО текст без коментарів."*
   - Час відповіді: **~400–600 мс**.
4. **Вставка тексту в активне поле вводу (`FlowPaste`)**:
   - Текст записується у `NSPasteboard` з маркерами `TransientType` та `AutoGeneratedType` (Raycast/Paste не засмічуються).
   - Емуляція натискання ⌘V через `CGEvent(keyboardEventSource: ...)`.
   - Оригінальний буфер обміну автоматично відновлюється через 700 мс.

## 3. Сервер сокетів та агентські хуки (`HookServer`)

1. **Сокет**: `~/Library/Application Support/DNK_Piu/piu.sock` (`chmod 0o600`, NDJSON).
2. **Аппрували Antigravity (`PreToolUse`)**:
   - Читає дозволи з `~/.gemini/antigravity-cli/settings.json`, глобальних грантів і проєктних правил.
   - Для команд без авто-дозволу показує картку погодження в нотчі (`Allow`, `Deny`, `Reply in terminal`).
3. **Хуки Hermes (Герича) та Claude Code**:
   - Генерація плагіна `~/.hermes/plugins/piu/__init__.py`.
   - Відображення карток сесій, статусів та запитів на погодження дій термінального білдера.

## 4. Суверенний AI-шар (Локальний міст Vertex AI)

- **Повне викорінення Anthropic API**: видалення обов'язкового `anthropic-api-key` з Keychain.
- **Ендпоінт**: `http://127.0.0.1:11435/v1/chat/completions` ([coucou_vertex_bridge.py](./scripts/system/coucou_vertex_bridge.py)).
- **Модель**: `google/gemini-3.8-flash`.
- **Функціонал**: чат, AI-cleanup диктування, виправлення пунктуації та створення нотаток.

### 6.2. `.github/workflows/build.yml`
```yaml
name: DNK_Piu CI Build

on:
  push:
    branches: [main, master, "dnk-mvp/**"]
  pull_request:
    branches: [main, master]
  workflow_dispatch:

concurrency:
  group: ${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: true

jobs:
  build-macos:
    name: Build & Package DNK_Piu
    runs-on: macos-15
    steps:
      - name: Checkout Repository
        uses: actions/checkout@v4

      - name: Setup Xcode
        uses: maxim-lobanov/setup-xcode@v1
        with:
          xcode-version: latest-stable

      - name: Install XcodeGen
        run: brew install xcodegen

      - name: Generate Xcode Project
        run: |
          cd DNK_Piu
          xcodegen generate

      - name: Build Application (Release)
        run: |
          set -o pipefail
          mkdir -p build_output
          xcodebuild \
            -project DNK_Piu/DNK_Piu.xcodeproj \
            -scheme DNK_Piu \
            -configuration Release \
            -derivedDataPath build_derived \
            CONFIGURATION_BUILD_DIR="$(pwd)/build_output" \
            CODE_SIGNING_ALLOWED=NO \
            CODE_SIGNING_REQUIRED=NO \
            build | xcbeautify || true

      - name: Ad-Hoc Code Sign & Package
        run: |
          APP_PATH="build_output/DNK_Piu.app"
          if [ ! -d "$APP_PATH" ]; then
            echo "::error::DNK_Piu.app not found in build_output!"
            exit 1
          fi
          
          echo "Applying Ad-hoc codesign..."
          codesign --force --deep -s - "$APP_PATH"
          
          echo "Packaging into zip..."
          ditto -c -k --keepParent "$APP_PATH" "build_output/DNK_Piu-macos-arm64.app.zip"

      - name: Upload Build Artifact
        uses: actions/upload-artifact@v4
        with:
          name: DNK_Piu-macOS-Release
          path: build_output/DNK_Piu-macos-arm64.app.zip
          retention-days: 14
```
