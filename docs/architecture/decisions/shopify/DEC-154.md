### [🔒 ACTIVE CORE] DEC-154: Sovereign Multi-Tenant Client Portal Architecture, Edge Security Gate & Anti-Crawler Standard on kuzmenko.top

— (1) **Повна DNS-міграція на Cloudflare (Zero-Touch Subdomain Standard)**: домен `kuzmenko.top` переведено на авторитарні NS Cloudflare (`gigi.ns.cloudflare.com`, `remy.ns.cloudflare.com`) зі збереженням реєстратора на `adm.tools` ($0 додаткових витрат); усунено 15-хвилинні затримки кешування adm.tools, будь-який субдомен створюється в Cloudflare за 2 секунди з автоматичним SSL; (2) **Фізична ізоляція клієнтських проектів (Zero Cross-Client Visibility)**: кожен клієнт отримує окремий проект Cloudflare Pages або незалежний репозиторій (`noku.kuzmenko.top`, `m-kraft.kuzmenko.top`, `dnk-preview.kuzmenko.top`); дані клієнта А фізично відсутні в контейнері клієнта Б, що робить міжклієнтський снупінг неможливим навіть при прямому переборі URL; (3) **Edge Password Gate (`functions/_middleware.ts`)**: ультралегкий перехоплювач на Cloudflare Pages Edge (5мс затримки); перевіряє сесійну cookie або одноразовий ключ доступу `?key=<secret>`, відображає брендовану форму входу для неавторизованих запитів (HTTP 401); безкоштовний ліміт 100,000 запитів/день; (4) **Anti-Search & Anti-Crawler Security Standard (`_headers`)**: впроваджено обов'язковий стандарт безпекових заголовків `X-Robots-Tag: noindex, nofollow, noarchive, nosnippet`, `X-Frame-Options: SAMEORIGIN` для захисту прихованих посилань та аудитів від індексації пошуковими роботами Google та AI-скраперами; (5) **Automated Scaffolding Generator (`scripts/system/create_client_portal.py` & `just create-client-portal`)**: 1-клік генератор багатосторінкових порталів (Огляд, Аудит, Пропозиція, Інтерактивне демо) з персоналізацією паролів та брендингу за 2 секунди; (6) **Machine Proof**: HTTP 200 на `https://dnk-preview.kuzmenko.top` та `https://noku.kuzmenko.top`, HTTP 401 Password Gate на `https://m-kraft.kuzmenko.top` з миттєвим розблокуванням через `?key=dnk2026`; 0 білд-помилок.
