### [🔒 ACTIVE CORE] DEC-110: Sovereign Workstation Topology (DNK_OS 8 Canonical Roots, 4-Zone APFS Runtime, Dual-Mount FastMCP Microkernel <400 LOC, and Spatial Canvas Orchestration Engine)

— Офіційна фіксація цільового фундаменту чистого суверенного простору `DNK_OS` на Apple Silicon: (1) **Narrow Waist Microkernel (`< 400 LOC`, 0 бізнес-логіки в ядрі)**: ядро виконує виключно System 1 тріаж (`< 50 мс`), маршрутизацію контрактів, перевірку безпеки Ring 0 та оркестрацію задач із замороженим префіксом `Sacred Prompt Cache <= 6,000 токенів`; (2) **3 Канонічні Воркхорси (`services/dnk_shopify`, `services/dnk_media`, `services/dnk_distribution`)**: уся прикладна бізнес-логіка інкапсульована у 3 доменних комбайнах за 5-елементним контрактом Суверенної Цеглинки (`brick.manifest.yaml`, `contracts/schemas.py`, `cli.py`, `mcp_server.py`, `tests/`); (3) **Dual-Mount FastMCP Execution**: прямий In-RAM Python-імпорт (`0 мс` затримки, `0 байт` серіалізації) для внутрішнього ядра та `CodeModeSandbox`, плюс тонка обгортка `mcp_server.py` (`stdio`/`SSE`) для зовнішніх IDE та агентів (Antigravity, Claude Code, Cursor); (4) **SCONES SQLite WAL (`FTS5 BM25 < 15 мс`) + Working-Tree AST (`Base ⊕ Diff` / `ast-grep < 20 мс`) замість Vector DB**: 100% детермінована когнітивна пам'ять і точний граф символів без фонових векторних демонів (Qdrant/Milvus) та галюцинацій ембедінгів; (5) **4-Zone APFS Runtime & Worktree Pool (`~/.dnk_runtime/`)**: розділення MacBook на 4 фізичні зони APFS із захистом від індексації Spotlight (`.metadata_never_index`), пакетним ядром `uv` (`link-mode = "clone"`) + `pnpm` CAS та пулом ізольованих Git Worktrees (`~/.dnk_runtime/worktrees/`, спавн `< 80 мс`, `0 байт` дублів); (6) **8 Канонічних Коренів (`DNK_OS/`)**: суворий інваріант кореневої директорії (`core/`, `services/`, `packages/`, `apps/`, `docs/`, `tests/`, `scripts/`, `infra/`) під автоматичним наглядом `RootHygieneGuard`; (7) **Spatial Canvas Orchestration Engine & Per-Node Isolated Chats (Dual-State)**: кожна нода просторового полотна розкривається в ізольований агентний чат (`session_id = node:{canvas_id}:{node_id}`) із власним JIT-вайтлістом скілів (`<= 6,000 токенів`), де `.canvas` зберігає чисту геометрію JSON Canvas 1.0 та затверджений `Crystallized Summary Pin`, а SQLite WAL (`dnk_dag_store.db`) зберігає історію діалогу ноди та чеки виконання (по ребрах `ContextWire` передається виключно кристалізований артефакт, а не сирий лог чату); (8) **Gerych Archival Chronicle (DEC-054)**: Гєрич веде паралельний історичний літопис трансформації.
