### [🔒 ACTIVE CORE] DEC-152: DeepSeek Superagent Prototype Assimilation (Attention Economy, Two-Layer Admission Gate, Immutable Mandate & Ticket Contract, 5-Second Command Backgrounding, Denchik Mandate Guard, and Transactional Outbox Worker Daemon)

— (1) **Attention Economy & Zero-Chat Silence Protocol**: закріплення принципу мінімізації когнітивного навантаження людини; агент підтверджує прийом задачі 1 раз, працює у повному мовчанні та повертається лише при переході у стан `ready` (готовий результат / PR) або `attention` (блокуюче рішення людини); (2) **Двошаровий Шлюз Авторизації (Gate $\rightarrow$ Eval $\rightarrow$ Mandate)**: детермінований `Gate` (`core/domain/mandate_contracts.py`: білий список авторів, перевірка відсікання ботів і спаму без LLM-витрат) $\rightarrow$ `Assessment` (оцінка доцільності) $\rightarrow$ `Immutable Mandate` (версія політики, строгий білий список шляхів, тип сили `explicit`/`inferred`); (3) **5-Second Command Backgrounding (`core/action_bus/command_runner.py`)**: команди терміналу, тривалість яких перевищує 5 секунд, автоматично трансформуються у фоновий асинхронний таск із негайним поверненням дескриптора сесії, запобігаючи блокуванню агентного циклу; (4) **Denchik Mandate Guard (`core/orchestrator/agents/denchik/builder_guard.py` & `core/security/tool_guard_pipeline.py`)**: суворий інваріант Stage 2, що перехоплює виклики `write_file`/`patch` та блокує вихід за межі `MandateScope`, спроби мутації `.env` або абсолютні шляхи; (5) **Transactional Outbox & Worker Daemon (`core/outbox/`)**: повідомлення у зовнішні канали (GitHub, Telegram, CLI) спочатку фіксуються в SQLite із квитанцією `receipt_id`, після чого обробляються фоновим воркером `OutboxWorkerDaemon` (`just outbox-drain` / `just outbox-daemon`) з експоненційним бекофом і дедуплікацією; (6) **FastMCP & CLI Integration**: 4 нові FastMCP тули в `core/kernel_mcp.py` зі збереженням вузької талії ядра (<400 LOC); (7) **Machine Proof**: 27/27 тестів у `just test-dsh` зелені (2.05с), 100% exit code 0 на всіх гейтах.
