# Do not Delete - Example

## 📋 Семантичний Опис Стандарту
Цей документ є візуальним та архітектурним еталоном оформлення документів у DNK OS.
Він демонструє бездоганне поєднання оптичного сприйняття людиною (**UX / Obsidian**) та детермінованого машинного парсингу AI-агентами (**Swarm / AST**).

### 🎯 Ключові Архітектурні Принципи
1. **Єдина Типографіка:** Шрифт `fontFamily: 2` (Normal Sans-Serif / Inter / Helvetica) гарантує 100% ідентичний, чистий вигляд тексту як для української (UA), так і для англійської (EN) мов.
2. **Flat Green Палітра:** Стримана плоска темно-зелена палітра (Forest Green `#16382b`, Dark Pine `#13221a`, Mint Highlight `#86efac`) без кислотності.
3. **Виразні Жирні Заголовки:** Кожна картка та секція має виокремлений акцентний заголовок контрастного м'ятного кольору, розташований у власній шапці.
4. **Нульове Налізання (Zero Overlap):** Сувора просторова сітка, широкі відступи між колонками (46px) та картками (18px).
