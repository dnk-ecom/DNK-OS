2. Архітектура Shopify Theme Blocks (Online Store 2.0)

На зідзвоні ти наголосив: «Хочеться, щоб деякі моменти можна було самостійно видаляти або додавати як блок».

Що таке Theme Blocks і чому це важливо для NOKU: Shopify 2.0 Native

У новій архітектурі Shopify кожен функціональний модуль (вибір комплекту, таблиця розмірів, фотоматеріали, відгуки, відеоінструкція монтажу) є **автономним будівельним блоком** у вашому стандартному редакторі теми (Shopify Customize).

  • ✓
    Управління мишкою без програміста: Ви або ваш менеджер можете перетягувати блоки місцями, додавати нові поля або тимчасово приховувати їх для конкретного товару в один клік.
  • ✓
    Нуль щомісячних абонплат за додатки: Комплектація, бандли та допродажі реалізуються на чистому нативному коді теми — вам не потрібно платити по $30–$50 щомісяця за сторонні віджети на зразок Kaching чи WideBundles.
  • ✓
    Максимальна швидкість на смартфонах: Нативні блоки не тягнуть зовнішніх важких скриптів, тому сторінки на телефонах замовників із США, Німеччини чи Польщі відкриваються миттєво (Core Web Vitals у зеленій зоні).
