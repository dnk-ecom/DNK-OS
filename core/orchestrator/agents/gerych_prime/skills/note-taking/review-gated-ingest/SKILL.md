# Review-Gated Knowledge Ingestion Protocol (Anti-Poisoning Gate)

## Overview
This skill operationalizes the **Anti-Poisoning & Gated Ingestion Protocol** (`./docs/notes/148_anti_poisoning_and_gated_ingestion_protocol.md`). It ensures that no external paper, GitHub repository, or LLM-generated R&D brief enters the persistent memory stores (Obsidian Vault and SCONES memory) without passing through a strict dual-verification barrier:
1. **Adversarial Provenance Verification** (`gerych_auditor`): Citation integrity, source verification, hallucination index $< 0.05$.
2. **Founder Human Approval** (Maxim / Antigravity): Explicit human sign-off.

---

## 🛑 Strict Invariants

1. **Zero-Direct-Memory-Write (ZDMW)**:
   - Worker agents (`gerych_builder`, `gerych_researcher`, `dnk_dev_fullstack`, `dnk_shopify`) NEVER write directly to `./docs/notes/` or call `scones_add_memory`.
   - Raw research must be output to ephemeral staging (e.g. `./core/orchestrator/agents/gerych_researcher/cache/research_raw/`).
2. **Librarian Exclusivity**:
   - Only `herich_librarian` executes vault ingestion and SCONES memory storage.
3. **Dual Gate Verification**:
   - Ingestion is rejected if either `auditor_token` or `founder_approval` is missing or invalid.
4. **Gold-Standard Vault Hygiene**:
   - Every note must strictly adhere to the 8 mandatory YAML frontmatter fields, hidden HTML MRH header, and viewport-friendly Mermaid diagrams.

---

## 📋 Step-by-Step Ingestion Workflow

### Stage 1: Verify Pre-Requisite Artifacts
Before writing to the vault, confirm the existence of:
1. **Raw Staged Brief**: Ephemeral markdown file produced by `gerych_researcher`.
2. **Audit Verification Report**: Generated by `gerych_auditor` confirming:
   - Real citations verified against web/arxiv/github.
   - Zero fabricated quotes.
   - Hallucination score $< 0.05$.
   - License classification verified (Track 1 Permissive vs Track 2 Clean-Room).
3. **Founder Approval**: Explicit confirmation in the conversation turn from Maxim (e.g. "погоджую", "даю добро", "записуй у vault").

### Stage 2: Calculate Sequential Dynamic Note Prefix
Inspect existing notes in `./docs/notes/` to prevent collisions:
```bash
python3 -c "
import os, re
notes = [f for f in os.listdir('./docs/notes') if f.endswith('.md')]
nums = [int(m.group(1)) for f in notes if (m := re.match(r'^(\d+)', f))]
next_num = max(nums) + 1 if nums else 1
print(f'Next available prefix: {next_num:03d}')
"
```

### Stage 3: Synthesize Gold-Standard Markdown Note
Structure the final note using the Gold-Standard Schema:
- **YAML Frontmatter**:
  - `title`: Canonical English title
  - `aliases`: List of 2-4 Ukrainian & English search aliases
  - `tags`: `[dnk-os, <category>, <keywords>]`
  - `type`: `ADR` | `ARCH` | `SOTA` | `STANDARD` | `GUIDE`
  - `status`: `active`
  - `created`: Current ISO date (`YYYY-MM-DD`)
  - `updated`: Current ISO date (`YYYY-MM-DD`)
  - `author`: `"Maksym Kuzmenko & Herich Librarian"`
- **Hidden MRH Header**: Directly following frontmatter:
  ```markdown
  <!-- --- DNK-MRH-HEADER ---
  mrh_id: "docs/notes/<NNN>_<slug>.md"
  purpose: "<concise purpose>"
  canonical_source: true
  alters_files: []
  triggers_tasks: []
  status: "Active"
  version: "1.0.0"
  updated_at: "YYYY-MM-DD"
  author: "DNK-e.com Maksym & Herich Librarian"
  --- END DNK-MRH-HEADER -->
  ```
- **Type-Emoji H1 & Abstract**:
  ```markdown
  # ⚖️ <Title>
  > [!abstract] **Контекст та призначення**
  > <Україномовний стислий підсумок>
  ---
  ```
- **Viewport-Optimized Diagrams**:
  Mermaid `flowchart TD` with `direction LR` subgraphs to ensure readability at 100% zoom.
- **Rich Bidirectional [[wikilinks]]**:
  Links to `[[000 DNK HUB Index]]`, relevant ADRs, and parent architectures.

### Stage 4: Atomic Vault Commit & Index Update
1. Write note to `./docs/notes/<NNN>_<slug>.md`.
2. Register entry into `./docs/notes/000 DNK HUB Index.md` under the appropriate category.
3. Validate links and frontmatter via:
   ```bash
   python3 core/orchestrator/agents/herich_librarian/scripts/verify_ingest_gate.py --file "./docs/notes/<NNN>_<slug>.md"
   ```

### Stage 5: Distill High-Signal Rules to SCONES Memory
Call `scones_add_memory` with atomic, durable rules:
```python
scones_add_memory(
    topic="<Canonical Topic>",
    content="[<PREFIX>] Invariant: <Deterministic rule learned from research/ADR>",
    importance=0.9,
    workspace_id="ws-alpha-001"
)
```
