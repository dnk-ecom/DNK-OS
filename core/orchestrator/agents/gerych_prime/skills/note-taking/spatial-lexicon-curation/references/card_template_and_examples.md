# Reference: Spatial Lexicon Card Template and Concrete Examples

## 1. 5-Point Card Format
```markdown
### <Index>. <Term Name in English> (<Українська назва>)
> **Ключова сутність**: <1-2 речення: лаконічне інтуїтивне пояснення>.

1. **Симптом болю / Що ламається без цього**:
   - Чому виникає проблема, який дефект проявляється в системі або у поведінці моделі.
2. **Архітектурне рішення & Механіка**:
   - Алгоритм, математична модель, структури даних, правила обробки.
3. **SOTA походження / Світові аналоги**:
   - arXiv препринти, репозиторії Google, Anthropic, Meta, DeepSeek або SOTA фреймворки.
4. **Шаблон коду / Архітектурний патерн**:
   ```python
   # Конкретна лаконічна реалізація або конфігурація
   ```
5. **Вайбкод-рецепт швидкої інтеграції**:
   - Як вайбкодеру або агенту використати цей блок за 2 хвилини для побудови нової фічі.
```

## 2. Real Example from DNK OS Spatial Lexicon
```markdown
### 1. Context Bloat (Засмічення Контексту)
> **Ключова сутність**: Падіння якості міркувань (reasoning decay) та деградація уваги моделі через захаращення контекстного вікна непотрібними файлами, гігантськими виводами та зайвими системними інструкціями.

1. **Симптом болю / Що ламається без цього**:
   - Модель "тупить", забуває вихідне системне завдання, починає фантазувати шляхи файлів або повторювати одні й ті самі тул-коли по колу (ReAct Loop Exhaustion).
2. **Архітектурне рішення & Механіка**:
   - JIT Tool Loading (підвантаження описів інструментів на вимогу).
   - Слайси файлів (Limit 80-120 рядків) замість читання цілих файлів.
   - Модульний поділ бази знань замість 2000-рядкових монолітних словників.
3. **SOTA походження / Світові аналоги**:
   - "Lost in the Middle" (Liu et al., 2023, Stanford).
   - Anthropic Context Caching Protocols.
```
