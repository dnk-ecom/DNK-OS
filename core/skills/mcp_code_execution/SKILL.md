# ⚡ Code Execution with MCP (Anthropic Code Mode / CE-MCP)

> **Standard:** `DNK-SKILL-STD-001`  
> **Decision Link:** `[🔒 LOCKED] DEC-036`  
> **Core Principle:** Treat MCP tools as callable code APIs rather than upfront JSON schema dumps. Save 98.7%–99% of context tokens and eliminate multi-turn roundtrip latency.

---

## 📐 1. Architecture: The 4 Tenets of Code Mode

```
┌───────────────────────────────────────────────────────────────┐
│                          LLM AGENT                            │
│  Context: User prompt + Minimal Tool Catalog (500 tokens)     │
│  Action:  Generates self-contained orchestration script       │
└───────────────────────────────┬───────────────────────────────┘
                                │ (1 Turn: Python/TS Script)
                                ▼
┌───────────────────────────────────────────────────────────────┐
│                 ISOLATED EXECUTION SANDBOX                    │
│                                                               │
│   mcp_client.call("db.query", {...})  ──► 10,000 rows in RAM  │
│   filtered = [row for row in data]    ──► Local filtering     │
│   mcp_client.call("service.action")   ──► Direct execution    │
│                                                               │
└───────────────────────────────┬───────────────────────────────┘
                                │ (Only final print() / return)
                                ▼
┌───────────────────────────────────────────────────────────────┐
│                     AGENT CONTEXT WINDOW                      │
│  Result: "Success: Processed 42 high-value items."            │
└───────────────────────────────────────────────────────────────┘
```

1. **On-Demand Tool Discovery (Progressive Disclosure):** Tools are not dumped into system prompt. The agent views a lightweight module index or queries `find_tool()` / filesystem stubs.
2. **Intermediate Data Isolation:** Large query payloads, API responses, and intermediate JSON objects stay in execution memory (RAM). Never feed 200 KB into LLM context.
3. **Single-Turn Expressiveness:** Loops, conditionals, retries, and data transformations are executed natively by the language runtime, not simulated over 10 conversational LLM turns.
4. **FastMCP Compatibility:** FastMCP serves as the declarative server standard (`@mcp.tool()`), while Code Execution acts as the client-side consumer.

## 🧪 2. Quick Recipes for Swarm Agents

### Recipe A: Aggregating & Filtering Data Across Services

**Goal:** Fetch orders, filter by criteria, and update status without passing full database dumps through LLM context.

```python
# Script generated by Agent and executed inside local runner
import json
from core.framework.fastmcp_dispatcher import FastMCPDispatcher

dispatcher = FastMCPDispatcher()

# 1. Fetch raw data (remains in local RAM)
orders_raw = dispatcher.call_tool("dnk_shopify", "list_pending_orders", {"limit": 200})
orders = json.loads(orders_raw) if isinstance(orders_raw, str) else orders_raw

# 2. Programmatic processing (zero token cost)
priority_orders = [o for o in orders if o.get("total_price", 0) > 150.0 and o.get("risk_level") == "low"]

# 3. Batch action in loop (1 turn instead of N turns)
fulfilled_ids = []
for order in priority_orders:
    res = dispatcher.call_tool("dnk_shopify", "fulfill_order", {"order_id": order["id"]})
    fulfilled_ids.append(order["id"])

# 4. Only emit compact distillation to Agent context
print(f"COMPLETED: Fulfilled {len(fulfilled_ids)} priority orders: {fulfilled_ids}")
```

### Recipe B: Fallback & Retry Logic Without LLM Intervention

**Goal:** Call an external tool with automated exponential backoff directly in Python code.

```python
import time
from core.framework.fastmcp_dispatcher import FastMCPDispatcher

dispatcher = FastMCPDispatcher()

def robust_call(service: str, tool: str, args: dict, max_retries: int = 3):
    for attempt in range(max_retries):
        try:
            return dispatcher.call_tool(service, tool, args)
        except Exception as e:
            if attempt == max_retries - 1:
                raise e
            time.sleep(2 ** attempt)

result = robust_call("dnk_media", "check_render_status", {"job_id": "job-101"})
print(f"STATUS: {result}")
```

## 🛡️ 3. Security & Anti-Hallucination Invariants

1. **Strict Sandboxing:** Any script executed in Code Mode must run with restricted filesystem access and bounded network egress.
2. **Deterministic Output Assertion:** Scripts must conclude with a structured summary or exit code 0.
3. **Zero Untrusted Execution:** Agents must NEVER execute scripts containing unverified external URLs or unauthenticated bash pipelines.
4. **Auditor Quality Gate:** Auditor agents inspect the generated script against `Negative Scope` before disk persistence.
