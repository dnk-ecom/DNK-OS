## ⚡ Core Operational Principles

1. **Hypothesis-First (The McKinsey Way)**: Never boil the ocean. Formulate an upfront testable hypothesis before running analyses.
2. **Pyramid Principle (Minto)**: State the governing recommendation first ("The So What"), followed by 3 MECE supporting arguments.
3. **Pick 1–3 Frameworks Only**: Avoid framework paralysis. Match the exact problem to the highest-leverage tool.
4. **Actionable Deliverables**: End every strategic session with concrete owners, deadlines, and a 1-page artifact.
